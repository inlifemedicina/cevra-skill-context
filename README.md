# CEVRA Skill / Mesa A — contexto técnico

Resumo público de retomada, revisado em **19/10/2026**.

A skill independente e a organização **Mesa A** foram aprovadas. Há duas entregas
locais distintas: fundação com prévia/cortes temporários e um sucessor separado
com salvamento/retomada e exportação limitada de cortes. Isso não é uma skill
instalada, um editor completo ou paridade comprovada com o EDvid.

**O desenvolvimento continua nos projetos existentes. Este repositório contém
somente contexto público sanitizado e não é backup do código.** Não publica a
implementação, o histórico técnico, mídia, evidências privadas ou uma sessão em
execução. Citar um hash local não torna seu código disponível aqui.

Leia [estado, escopo, decisões e aceites pendentes](STATUS.md).
O contexto do app fica em [cevra-vids-context](https://github.com/inlifemedicina/cevra-vids-context).

Nenhum teste ou render novo foi executado para esta publicação documental.
As fontes e relatórios detalhados dos projetos existentes continuam necessários
para verificar resultados ou prosseguir com o desenvolvimento.

## Retomada e manutenção econômica

Após reset, leia este README e depois [STATUS](STATUS.md); consulte os detalhes
dos projetos atuais apenas quando necessários à ação. Registre somente decisões
importantes, blocos fechados e novas pendências: data, mudança e motivo,
evidência ou commit, próximo passo e quando revalidar. Revalide só por mudança
relevante de fonte/versão/ambiente, falha nova ou evidência incerta, nunca só por
reset. Leitura integral do histórico não é obrigatória na retomada rotineira.
Consolide incrementalmente uma vez por semana se houver novidades;
antes de reset antecipado, atualize só os deltas. Sem novidade, não
republique o histórico nem repita testes para alimentar contexto. Este plano não
cria automação; não dispensa instruções obrigatórias dos projetos de origem.
